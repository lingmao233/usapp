# 账号系统与导航重构设计

> 2026-08-17 经 grilling 会话逐分支确认的共识方案。前置背景：个人功能上线后移动端顶栏「我们」与「碎片墙」重叠（第 5 个 tab 撑爆 flex），且个人恢复码体系被账号体系取代。

## 一、账号系统（取代个人码登录）

- **账号名全局唯一 + 密码（可空、无任何格式要求）**。所有数据绑定账号（`accounts`）。
- 注册成功后**强制展示一次找回凭证**：可当场自设（复用 CodeCustomizer）/复制，点"我已保存"才进 App。凭证仅用于忘密码时重置密码。
- 个人恢复码登录体系整体作废；`recovery_code` 字段保留但语义改为"找回凭证"。
- 主界面 = 账号登录/注册，**无邀请码**。邀请码只剩一个用途：进圈子（圈主可自设，设置页可查看，个人→加入新圈子时输入）。
- 测试数据全清，schema 直接重建，不做存量迁移。

## 二、登录后结构

- 登录落地二选一：**圈子 / Self**。
- 圈子：多圈用户先出圈子选择页；无圈时引导新建/加入。
- Self：账号级数据（目标/每日计划/记账/热量/鞭策设置），跨圈唯一一份，挂在 `account_id` 上。
- 同一账号在不同圈子可有不同昵称（沿用 `memberships` → `users` 每圈一身份）。

## 三、圈内顶栏

- 4 个 tab：**碎片、愿望清单、朋友任务、关系**。
- **搜索图标**（顶替知识库入口）：点开为搜索页，全局搜碎片+知识库+愿望；空搜索默认展示知识库列表。
- **汉堡下拉**两项：
  - 设置：查看本圈邀请码、设置圈子人格。
  - 个人：我的圈子列表、点击跳圈、新建圈子、加入新圈子。
- 「我的」从顶栏移除——移动端重叠随之消除。

## 四、Self 共享与朋友任务

- 共享粒度：**类别 × 圈子开关**（`self_sharing(account_id, circle_id, category, level)`，category ∈ goal/plan/ledger/calorie）。
- 目标与每日计划额外分**仅进度 / 详细数据**两档（level ∈ progress/detail）；记账/热量只有开关无档位。
- **朋友任务**页：聚合圈内成员共享出来的目标+每日计划，按人分卡，带鞭策按钮（限频同人一天一次、按人屏蔽、关鞭策等现有规则不变）。
- 记账/热量本期不开放共享开关（无展示出口），表结构预留 category。

## 五、前端瘦身（本次附带）

- 删除约 40 个零业务引用的 `src/components/ui/` 组件（含 sidebar.tsx 726 行、chart/menubar/context-menu/carousel/calendar 等）及其独占依赖（recharts/embla-carousel/cmdk/vaul/input-otp/react-hook-form/zod/next-themes/sonner/react-day-picker/react-resizable-panels 与未用 radix 包）。
- 保留业务实际引用的约 11 个组件（sheet/dialog/dropdown-menu/button/input/label/separator 等）。
- 不拆 Wall/Onboarding 大页面；不动 `weapp/`；零新依赖。

## 六、后端改动面

- `accounts`：+ `username`（唯一）、+ `password_hash`（可空）；`recovery_code` 语义改为找回凭证。
- auth 接口：`POST /api/auth/register`、`POST /api/auth/login`、`POST /api/auth/reset`（找回凭证→重设密码）。
- 目标/计划/记账/热量相关表：`user_id` → `account_id`。
- 新增 `self_sharing` 表与读写接口；新增朋友任务聚合接口（服务端按观看者过滤，隐私铁律不变：未共享的数据绝不出现在他人屏幕）。
- 测试沿用强制 mock 模式补齐。

## 七、明确不做

- 不做找回凭证以外的任何找回渠道（无邮箱/手机）。
- 不做跨圈 Self 全局视图的展示页（数据本来就是账号级一份，无需聚合）。
- 不做记账/热量的圈内展示。
- 不做大页面拆分重构。
