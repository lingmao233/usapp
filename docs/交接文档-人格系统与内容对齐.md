## 1. 本轮共识（已和用户敲定，不要翻案）

**目标**：周报口吻去"人机感"。两条路同时做：

- **A. 人格系统**：每圈一个人格，预写库 + 自定义，任何成员可换，**圈与圈不互通**
- **B1. 内容对齐（轻量 RAG）**：从圈内**公开**碎片/评论学说话风格，写周报时注入真实语录当 few-shot

**明确不做**：
- B2 真·微调训练（数据量几百条，差着数量级；成本与维护都不划算）
- C. AI 自动评论碎片（缓期。备忘两条护栏：bot 身份独立于 users 表、**永远不进亲密度算法**；只评论公共碎片。人格 + 语录底座做完后它就是小活）

## 2. 实施规格

### 2.1 数据层（迁移仿 `server/app/db/database.py` 现有 PRAGMA 模式）

- `circles` 加两列：`persona_preset TEXT NOT NULL DEFAULT 'observer'`、`persona_custom TEXT NOT NULL DEFAULT ''`
- `user_profiles.profile` JSON 里加一个 `style` 维度（见 2.4），无表结构变更

### 2.2 人格库（`server/app/ai/prompts.py`）

预设字典 `PERSONAS: dict[str, str]`，key → 人格 prompt 片段。五套起步（措辞可润色，气质别变）：

| key | 人格 | prompt 片段要点 |
|---|---|---|
| `observer` | 朋友圈观察员（默认） | 现有人格：轻松幽默，像朋友聊天 |
| `sunshi` | 损友 | 毒舌但暖心，爱吐槽，吐槽里全是关心 |
| `shudong` | 温柔树洞 | 细腻共情，像深夜电台，句子软 |
| `weekly` | 编辑部周刊 | 正经媒体腔的戏仿，拿小圈子的事当头条写 |
| `laba` | 村口大喇叭 | 热情外放爱起哄，感叹号多，自来熟 |

人格解析顺序：`persona_custom` 非空 → 自定义文本当人格；否则查 `PERSONAS[persona_preset]`，查不到回退 `observer`。

### 2.3 API（沿用现有"query param 传 user_id"的零鉴权现状）

- `POST /api/circles`：`CreateCircleIn` 加可选 `persona_preset` / `persona_custom`
- `PUT /api/circles/{id}/persona`：body `{user_id, persona_preset, persona_custom}`，校验该 user 属于该圈（参照 `fragments.py` 现有的成员校验写法），任何成员可改
- `GET /api/circles/{id}`：响应带 persona 两字段

### 2.4 B1 内容对齐

1. **风格蒸馏**（每晚管线顺带做）：`generate_user_profile`（`ai/__init__.py` + `USER_PROFILE_PROMPT` + `mock.py` 的桩）输入增加该用户近期**公开**碎片/评论摘录，输出 JSON 加 `style` 键（口头禅、用词习惯、emoji 偏好、句子长短）。mock 桩要确定性地产出该键。
2. **语录检索**（周报生成时）：`reports.py` 的 `_collect_week_data` 里加一步：圈内**公开**碎片 + 评论原句，优先互动多的（like/comment 计数）+ 补几条最近的，共 ≤8 条，每条截 50 字。**只用公开内容，隐私碎片/隐私圈外内容永远不进 prompt**（铁律，设计文档 §5）。
3. **prompt 组装**：`WEEKLY_REPORT_PROMPT` 加 `{persona}` 和 `{quotes}` 两个占位：
   - persona 段：「请用这个人格的口吻写：{persona}」
   - quotes 段：「以下是大家最近说过的话，学习这种语感，可以引用或玩梗，但不要大段照抄：{quotes}」
   - 现有"事实与猜测的分寸"规则**原样保留**，放在人格段之后（人格管语气，规则管事实，互不覆盖）

### 2.5 前端（`src/`）

- `src/core/types.ts` / `api.ts`：Circle 类型与 createCircle/新 updatePersona 方法（可选参数，向后兼容）
- `Onboarding.tsx` 建圈表单：人格选择 chips（五个预设）+ 展开"自定义"输入框
- `App.tsx` 顶栏：桌面操作区与移动端下拉菜单加「圈子人格」入口 → 弹层（用现有 shadcn 组件）查看/切换人格、编辑自定义文本
- 不新增路由，不动 weapp

## 3. 测试要求

`server/tests/` 新增（风格参照 test_visibility.py / test_memory.py，强制 mock）：

1. 人格 CRUD：建圈带人格、成员改人格、非成员 403、两圈人格互不影响
2. prompt 组装：人格文本与语录出现在最终 prompt（把 prompt 组装拆成纯函数再断言）；无自定义时回退预设、预设查不到回退 observer
3. 语录边界：隐私碎片/隐私碎片的评论**不出现**在 quotes；互动多的公开碎片优先入选
4. 风格蒸馏：`style` 键出现在 user_profiles（mock 确定性断言）

验收：全量 pytest + smoke 48 断言无回归；`npm run build`；`cd weapp && npx tsc --noEmit`。

## 4. 手测路径（真实 key 下）

1. `npm run dev`，建圈选「损友」，发几条碎片，跑一次 `POST /api/reports/generate`（force 刷新已内置）看口吻
2. 换自定义人格（如"像佟掌柜"）再生成一次对比
3. 顶栏菜单换人格后确认 GET circle 返回已更新
4. 注意事项：改 `.env` 后必须重启后端；周报有 10 分钟滚动刷新窗口，手测用 POST /generate 强刷
